# 競技場突圍

第一人稱 3D 網頁射擊遊戲：在霓虹競技場中通過三波敵人，並在生命值歸零前存活。

## 目前功能

- 三波敵人：每波數量與移動速度遞增，第三波敵人需要更多命中
- 擊倒敵人可得 100 分
- 競技場柱體會阻擋玩家移動，也會遮擋射擊
- 波次間可選擇繼續；生命值不會自動回復
- 玩家生命值歸零或清除三波敵人時結束本局

## 美術

目前採霓虹賽博龐克風格；敵人、武器、場景燈條與地面標記由 Three.js 幾何和材質程式化製作，未使用外部素材。

## 操作方式

- **WASD**：移動
- **滑鼠**：瞄準
- **滑鼠左鍵**：射擊
- **Shift**：衝刺
- **Esc**：暫停或繼續

## 執行

遊戲透過 CDN 載入 Three.js，需有網路連線。請在專案資料夾開啟終端機並執行：

```sh
node server.js
```

接著用瀏覽器開啟 <http://127.0.0.1:8000>。點擊「進入競技場」即可遊玩；若瀏覽器不允許鎖定滑鼠，移動游標仍可瞄準。
