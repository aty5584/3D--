# 競技場突圍

第一人稱 3D 網頁射擊遊戲：在 48×48 的廢棄工廠多通道場地中通過三波敵人，並在生命值歸零前存活。

## 目前功能

- 三波敵人：每波數量與移動速度遞增，第三波敵人需要更多命中
- 擊倒敵人可得 100 分
- 競技場柱體會阻擋玩家移動，也會遮擋射擊
- 波次間可選擇繼續；生命值不會自動回復
- 玩家生命值歸零或清除三波敵人時結束本局
- 三種武器：手槍、突擊步槍、狙擊槍
- 滾輪切換武器，每把槍使用獨立彈匣與備彈
- 可按 `R` 換彈
- 狙擊槍可按住滑鼠右鍵開啟 3 倍瞄準鏡
- 廢棄工廠多通道場地，含管線、警示標記與可阻擋移動及射擊的掩體
- 開火時會顯示依武器配色的飛行彈丸與短暫尾跡

## 美術

場地採明亮的廢棄工廠風格，加入夕陽天空、工作燈與較清晰的地面、掩體照明；敵人、武器、管線、掩體與地面標記由 Three.js 幾何和材質程式化製作，未使用外部素材。

## 操作方式

- **WASD**：移動
- **滑鼠**：瞄準
- **滑鼠左鍵**：射擊
- **突擊步槍**：按住滑鼠左鍵連續射擊
- **滑鼠滾輪**：切換手槍／突擊步槍／狙擊槍
- **R**：換彈
- **滑鼠右鍵（狙擊槍）**：按住開鏡
- **Shift**：衝刺
- **Esc**：暫停或繼續

## 執行

遊戲透過 CDN 載入 Three.js，需有網路連線。請在專案資料夾開啟終端機並執行：

```sh
node server.js
```

接著用瀏覽器開啟 <http://127.0.0.1:8000>。點擊「進入競技場」即可遊玩；若瀏覽器不允許鎖定滑鼠，移動游標仍可瞄準。
